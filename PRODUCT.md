# Synas Labs — Lead-to-Sale CRM
# Product Source of Truth (Phase 0)

## Positioning

Lead-to-sale operating system for US residential real estate that turns incoming
leads into structured opportunities, property matches, follow-ups, showings,
proposals, negotiations and closed revenue.

## Vertical

- Real estate
- Market: United States
- Currency default: USD ($)
- Timezone: workspace setting (default America/New_York)
- Dates: MM/DD/YYYY
- Phone: +1 (E.164)

## Phase boundary

Prompt 1 / Phase 0 = Foundation + Core Product.

Deferred to Prompt 2:
- Full AI intelligence layer
- AI follow-up drafting
- Property matching engine
- Advanced scoring / automation / insights / reports
- Final visual elevation

## Demo environment

Demo Mode is opt-in (`DEMO_MODE=true`) and isolated from production.

Seed creates local demo users. Provision the password through `DEMO_SEED_PASSWORD`.
Do not commit or publish demo passwords.
